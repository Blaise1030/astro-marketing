## Same repo, shared site

Invite teammates on the GitHub repository. Everyone opens the same project in Orso: writers use content forms, developers review diffs or ask the agent for larger changes.

## Review before publish

Create a change for anything that should go through review. Use **Share preview** so others can check the result, then publish when the change is ready.

## No extra seats to buy

Orso is free and open source. Team access follows your GitHub permissions and the agent subscriptions you already pay for.
