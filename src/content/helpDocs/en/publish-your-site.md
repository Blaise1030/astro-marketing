## Before you publish

Check the preview, then ask for a **greenlight** on the change. When it is approved, choose **Publish** to send it live.

Orso publishes static files. Your site can go live on GitHub Pages, Cloudflare, or any static host your repository already deploys to.

## After it is live

Visit the live site and confirm the change looks right. If something is off, restore an earlier version from **History** and publish again.

## Custom domains

Point your domain at whichever host serves the site. For Cloudflare, use the Cloudflare dashboard; for GitHub Pages, use the repository Pages settings. DNS changes can take a few minutes.
