## Edit an article

Open **Content**, choose **Help**, and select an article. Update the title, description, body and fields, then save. Orso writes the Markdown file in your project.

## Categories

Each article belongs to a section, which appears as a card on the Help home. Use **order** so related articles read in a sensible sequence.

## Subcategories

Add a subcategory to group related articles inside a section when the list grows long.
