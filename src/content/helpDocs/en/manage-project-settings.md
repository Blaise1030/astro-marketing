## Open settings

With a project open, use **Settings** to review the local folder, the linked GitHub repository, and which coding agent handles larger edits.

## Connect GitHub

Link a repository so you can create a change, share a preview, and publish. Orso works in the same repo your team already owns — there is no separate Orso hosting account.

## Choose an assistant

Pick the coding assistant Orso should use. **OpenCode** is the easiest start: it runs free models and needs no account. Claude Code, Codex and Cursor work too if you have an account. Orso installs and updates the assistant's tools for you.

## Approvals

By default the assistant asks before it fetches a web page, edits a file or runs a command. Requests appear one at a time above the chat box — choose **Allow** or **Deny**. To let it work without asking, switch the chat to **Auto-approve**.
