## What Orso is

Orso is a free desktop studio for Astro sites (macOS first). Edit Markdown in forms, or ask Claude, Cursor or Codex for bigger changes. Preview every draft locally — content stays in a Git repo you own.

## Open a project

Create a site from the Astro marketing template, or open a repository from GitHub. Orso starts a local preview of the project.

An existing Astro site needs the Orso Astro integration and supported collection loaders before its entries appear under **Content**.

## Edit content

Open **Content** to browse the site's supported Astro collections. Select a post or help article, edit its body or fields, and save. Orso updates the Markdown file in the project.

## Make a larger change

Open the agent panel and describe what you want in plain English. Review the result in **Preview**. Create a **change** before editing when the project is linked to GitHub, then use **Share preview**, get a **greenlight**, and **Publish** when it is ready to go live.
