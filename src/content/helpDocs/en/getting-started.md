## Open a project

Create a site from the Astro marketing template or open a repository from GitHub. Orso starts a local preview of the project.

## Edit content

Open **Content** to browse the site's supported Astro content collections. Select a post or help article, edit its body or fields, and save. Orso updates the Markdown file in the project.

An existing Astro site needs the Orso Astro integration and supported collection loaders before its entries appear for editing.

## Make a larger change

Open the agent panel and describe the site change you want. Review the result in **Preview**. For a GitHub-backed project, create a change before editing, then use **Share preview** or **Publish** when the result is ready.
