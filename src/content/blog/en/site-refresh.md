We've updated the Orso site to make it easier to read and quicker to scan.

## What's new

- **A clearer landing page.** We reworked the hierarchy and composition so each section has one job and the page reads top to bottom without clutter.
- **A centered hero.** The heading and supporting text now sit in the middle of the page, so the main message is the first thing you see.
- **Refined typography.** We tuned type sizes, weights, and spacing for comfortable reading.
- **Light and dark mode.** The site follows your system's theme preference, so it matches the rest of your setup.
- **A consistent primary action.** The main call to action uses one blue, so it's easy to find.

## How it was made

The whole refresh was done by asking an agent in Orso to change the site's design, then checking each change in the live preview. Because the site is an Astro project in your repository, the changes are ordinary code you can review and publish through your usual workflow.
