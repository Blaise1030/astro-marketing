## Welcome

Orso is a free desktop studio for Astro sites. Edit Markdown in a real UI, or ask Claude, Cursor or Codex. Preview every draft locally, publish static files to the host you choose, and keep everything in a Git repo you own.

## Two ways to work

For content in Astro collections — blog posts, help articles, and similar — use the forms in **Content**. Orso writes those edits straight to Markdown in your project.

When a change reaches beyond an article — layout, design, or code — describe it to the agent you already pay for. Same site, same repo, two doors in.

## Preview, then go live

Every change gets its own draft and a local preview on desktop and mobile. Share a preview for review, greenlight it when it looks right, then publish. The output is static files, so GitHub Pages, Cloudflare, or any static host you already use can serve it.

macOS is first. The studio is open source, so the site still builds and deploys if you leave Orso.
